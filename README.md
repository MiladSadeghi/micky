# میکی

دستیار صوتی هوشمند فارسی. نرم‌افزار هوش مصنوعی بیش از حد پیچیده شده؛ میکی یک همراه کوچک است، نه یک فضای کار. حرف بزن، کار راه بیفتد.

ساخته‌شده با Electron، Vite، و شنوای محلی. برای ایجنت‌ها و ساختار پروژه: [AGENTS.md](./AGENTS.md).

## توسعه

```bash
pnpm install
pnpm dev
```

## بررسی

```bash
pnpm typecheck
pnpm test
```

## مهارت‌ها

میکی مهارت‌های سراسری نصب‌شده با [skills.sh](https://skills.sh) را خودکار پیدا می‌کند. برای نصب یک مهارت در مسیر مشترک:

```bash
npx skills add owner/repo -g -a universal
```

مهارت‌ها را می‌توان از تنظیمات میکی، یک‌جا یا جداگانه روشن و خاموش کرد.

## بیلد

```bash
pnpm dist
```
