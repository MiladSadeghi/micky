# میکی

دستیار صوتی هوشمند فارسی. نرم‌افزار هوش مصنوعی بیش از حد پیچیده شده؛ میکی یک همراه کوچک است، نه یک فضای کار. حرف بزن، کار راه بیفتد.

ساخته‌شده با Electron، Vite، و شنوای محلی. برای ایجنت‌ها و ساختار پروژه: [AGENTS.md](./AGENTS.md).

## توسعه

```bash
pnpm install
pnpm dev
```

## بررسی

```bash
pnpm typecheck
pnpm test
```

## بیلد

```bash
pnpm dist
```
